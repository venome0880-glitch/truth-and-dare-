# ⚡ Truth or Dare - Pro Player Wheel Spinner

An interactive, responsive party game spinner built with modern HTML5 Canvas, Tailwind CSS, and Web Audio API.

## ✨ Features
- 👥 **Dynamic Player Wheel**: Player names directly displayed on wheel sectors.
- 🎯 **Minimum 2 Players Requirement**: Visual indicators and in-app notices if trying to spin with fewer than 2 players.
- 🎬 **Turn Announcement Modal**: Shows *"It's your turn, [Player]"* with glowing neon pink accents and an **Awesome!** confirmation button.
- 💬 **Truth or Dare Challenge System**: Curated library of fun truths and dares with reroll support.
- 🎨 **Obsidian Black & Electric Blue Cyber Theme**: Sleek neon glow, glassmorphic cards, and fluid quintic ease-out inertia physics.
- 🔊 **Synthesized Web Audio**: Procedural tick sounds as pegs pass the pointer and victory chimes upon landing.
- 🍾 **Multi-Mode Support**: Includes *Player Wheel*, classic *Truth vs Dare*, and *Spin the Bottle*.

## 🚀 How to Run
Simply open `index.html` in any modern web browser or serve it with GitHub Pages!
